## 2026-09-16 - Add aria-labels to GraphNavbar\n**Learning:** The GraphNavbar component in the policy-graph feature had multiple icon-only buttons lacking accessible labels, which is a critical accessibility issue for screen readers. This pattern of using only tooltips ('title') without 'aria-label' was identified and corrected.\n**Action:** When creating or reviewing UI components with icon-only buttons in the future, ensure 'aria-label' attributes are always included alongside visual tooltips for full accessibility.
