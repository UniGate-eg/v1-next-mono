## 3. Schema & Validation Specifications

### University Entity
- `id`: CUID generated by Prisma
- `slug`: Lowercase hyphenated, derived from `Short Name` (e.g., `"auc"`, `"guc"`, `"asnu"`)
- `nameEn`: String, from `University Name`
- `nameAr`: String, from bilingual enrichment dictionary
- `shortName`: String, from `Short Name`
- `type`: `UniversityType` enum (`PRIVATE` for File 1, `NATIONAL` for File 2)
- `educationModel`: `EducationModel` enum (`AMERICAN`, `GERMAN`, `BRITISH`, `EGYPTIAN`, `FRENCH`, `CANADIAN`)
- `governorate`: String, normalized Egyptian governorate
- `publishStatus`: `PublishStatus.PUBLISHED`
- `completenessScore`: Integer (calculated via CompletenessScoreEngine)

### Faculty (Academic Unit) Entity
- `id`: CUID generated by Prisma
- `universityId`: Foreign Key referencing `University.id`
- `nameEn`: String, from `Academic Unit Name`
- `nameAr`: String, localized Arabic name or standardized fallback
- `departments`: String array of sub-specializations or academic units

### DegreeProgram (Academic Offering) Entity
- `id`: CUID generated by Prisma
- `slug`: Lowercase hyphenated, scoped as `${uniShort}-${slugify(programName)}`
- `universityId`: Foreign Key referencing `University.id`
- `facultyId`: Foreign Key referencing `Faculty.id` (resolved via Excel `Academic Unit ID` mapping)
- `nameEn`: String, from `Official Name`
- `nameAr`: String, standardized Arabic translation
- `degreeType`: String, from `Offering Type` (e.g. `"Bachelor"`, `"Program"`, `"Major"`)
- `durationYears`: Integer (default 4)
- `studyLanguage`: String (default `"English"`)

## 4. Referential Integrity & Deletion Cascade Rules

- `University` $\rightarrow$ `Faculty`: `onDelete: Cascade`
- `University` $\rightarrow$ `DegreeProgram`: `onDelete: Cascade`
- `Faculty` $\rightarrow$ `DegreeProgram`: `onDelete: SetNull`
- `University` $\rightarrow$ `Bookmark`: `onDelete: Cascade` (purges bookmarks pointing to unverified deleted universities)
- `University` $\rightarrow$ `Suggestion`: `onDelete: Cascade`
- `User`, `Session`, `Account`, `Role`, `Permission`: **Untouched** (preserved completely)
