## 2024-05-24 - Memoize and Hoist Invariant Allocations in React .filter()
**Learning:** In React components, performing O(N) filtering operations directly in the render body causes unnecessary recalculations on every render. Furthermore, allocating objects (like `new Date()`) or applying formatting (like `toLowerCase()`) *inside* the `.filter()` loop exponentially worsens performance as data scales, as these invariant operations are needlessly re-evaluated for every single item.
**Action:** When filtering or mapping over arrays, always wrap the logic in `useMemo` to prevent recalculation on unrelated re-renders. Additionally, identify invariant operations (e.g., date instantiations or search string transformations) and hoist them outside the loop to execute only once per array processing cycle.
