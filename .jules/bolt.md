## 2024-03-20 - Zustand Destructuring Performance Issue\n**Learning:** Destructuring the entire Zustand store (e.g., `const { selectedUniversities, toggleUniversity } = useCompareStore();`) causes the component to re-render whenever ANY part of the store changes. This is a common performance anti-pattern, especially in list components where every item subscribes to the whole store. Instead, use granular selectors (e.g., `useCompareStore((state) => state.selectedUniversities.some((u) => String(u.id) === uniIdStr))`).\n**Action:** Always use granular selectors for Zustand stores, especially in list/card components.
