## 2024-05-25 - Caching Extracted Tokens in Major Match Engine
**Learning:** React `useMemo` hooks over entire databases (like `universitiesDatabase`) run computationally heavy logic inside the main thread rendering phase. The `MajorMatchEngine` was re-joining string arrays (~3500 `Array.join(" ")` ops per load) for every major and university combination because `getMatches` runs on render. Although `engine` was memoized, it lacked internal caching.
**Action:** When filtering across Cartesian products (e.g., all majors × all universities), cache intermediate extraction values (like `tokens.join(" ")`) per `source.sourceName` + `universityId` internally in the matching engine. Use `WeakMap` for safely caching pre-processed lookup keys (like lowercased `MajorDefinition.keywords`) to avoid risky object mutation.
