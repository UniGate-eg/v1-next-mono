## 2024-05-24 - Missing ARIA Labels in Complex UI Overlays
**Learning:** In complex, icon-heavy UI components (like the `policy-graph` module's navigation and inspector panels), developers often use `title` attributes for tooltips but frequently omit `aria-label`s. This is common when visual space is highly constrained and icons are heavily relied upon. While `title` helps mouse users, `aria-label` is crucial for screen readers to navigate these complex interactive layers correctly.
**Action:** When reviewing or creating map/graph overlays, or floating action bars where text is omitted to save space, actively verify that every icon-only `<button>` or interactive element has an explicitly defined `aria-label` that either matches or provides more context than the `title` attribute.
