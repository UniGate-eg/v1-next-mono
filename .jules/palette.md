## 2024-03-01 - Proper ARIA Attributes for Custom Password Toggle Buttons
**Learning:** In standard HTML inputs, basic accessibility can often be inherited, but when building custom interactive UI components like password visibility toggles, screen readers won't know their purpose without explicit ARIA labels. Additionally, custom toggle buttons must communicate their current state using `aria-pressed`, and decorative or redundant icons within these buttons should be hidden using `aria-hidden="true"` to prevent screen readers from reading out confusing or repetitive information.
**Action:** When creating or reviewing custom input toggles or icon-only buttons in forms, always ensure `aria-label` clearly describes the action, `aria-pressed` or `aria-expanded` (if applicable) accurately reflects the state, and `aria-hidden="true"` is applied to the visual icon. Also, always ensure inputs have `id` attributes that match the `htmlFor` of their corresponding labels, and use `aria-describedby` alongside `aria-invalid` to link inputs directly to their error messages.
